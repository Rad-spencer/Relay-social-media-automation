# Security boundaries

Implemented: parameterized SQL, Zod request validation, scrypt with random salts, random 256-bit session tokens stored as hashes, seven-day session expiration, HTTP-only SameSite=Lax cookies, Secure cookies in production, CSRF tokens on authenticated writes, origin checking, workspace membership lookup on each request, server-side role checks, Helmet headers, request body limits, process-local request/login throttling, constant-time HMAC checks with freshness window, event deduplication and append-only audit records through the API.

Roles: owners/admins configure and export; agents reply/edit contacts; analysts/viewers cannot mutate business records. Notification read state is a personal UI action currently stored workspace-wide. The database role and process owner are trusted administrators. There is no row-level security policy, MFA, email verification, recovery flow, invitation flow, or central rate limiter yet.

Raw text is rendered through React, never dangerouslySetInnerHTML. Template variables do not execute code. Approved URLs require HTTPS and reject credentials and obvious private IP destinations. The server never fetches arbitrary customer URLs; no scraping, website ingestion or file upload endpoint is implemented. Tracked links only redirect to a frozen approved destination, require an active resource and disclose no contact IDs. Clicks are aggregate counts; no IP addresses are collected for attribution.

Social connection tokens are encrypted with AES-256-GCM using a server-only key and authenticated workspace/provider/account context. See SOCIAL_LOGIN.md for state, PKCE and OIDC validation. Login-only tokens are not persisted. Key rotation, remote revocation and provider deletion callbacks remain deployment work. There are no LLM credentials. Browser cookies/CSRF secrets must never be logged. Error logs contain a generated request ID, error code and error type rather than request contents. Audit detail can contain customer text and therefore needs a retention policy before production.

Remaining production requirements: shared distributed rate limits, audit retention and tenant export/deletion policies, monitoring, account recovery/verification, threat-model and penetration review, live-adapter token encryption and signature tests, action outbox idempotency, provider rate limits, consent/window enforcement, secure deploy/backup controls, and load tests.
